# 미완료 글 직접 재수집과 저장 구간 빠른 재탐색

## 문제와 목표

사용자는 이전 종료 지점에 도달하는 데만 약 10분이 걸리고, 그동안 미완료 묶음도 해결되지 않는다고 보고했다. 현재 수동 재시작은 새 프로필 탐색이며 저장된 미완료 주소를 직접 방문하지 않는다. 이미 저장한 화면에도 새 화면과 같은 스크롤 간격을 사용한다.

목표는 전체 프로필 재탐색 없이 미완료 주소를 순서대로 방문하는 선택지와, 기존 본문을 다시 확인할 때의 대기 시간을 줄이는 것이다. Threads의 가상화 목록을 임의 위치로 건너뛰거나 날짜를 완전 확보 경계로 추측하지 않는다.

## 시험 경계와 구현 순서

사용자가 위임한 개발 범위 안에서 기존 공개 경계인 확장 메시지 처리·저장 응답·실제 reader를 쓰는 모의 페이지 이동·팝업 버튼을 검증한다. 기존 증상을 잡는 실패 시험을 먼저 실행하고 세로 단위로 구현한다.

1. 저장된 미완료 묶음이 현재 화면에 없어도 주소로 직접 이동하는 시험을 추가한다. 중지된 동일 계정에서 `미완료 글만 다시 수집`을 선택하면 저장소의 검증된 첫 글 주소만 큐에 넣는다.
2. 기존 상세 판독을 재사용하되 저장 확정 후 다음 미완료 주소로 이동한다. 완료 묶음은 제외하고 각 상세의 진전·시간 상한과 전체 실행의 시간 상한은 유지한다. 실패 사유는 보존하며 한 실행에서 같은 실패를 반복하지 않는다.
3. 큐 이동마다 실행 신원을 갱신해 이전 페이지 메시지를 거절한다. 탭 로딩·재주입·중지·대상 이탈·저장 실패를 시험한다. 마무리는 명시적인 프로필 주소로 복귀하며 자동 일반 수집을 시작하지 않는다.
4. 저장 응답에 기존 자료와 일치하는 깨끗한 프로필 화면인지 알려주는 값을 추가한다. 본문·첨부·번호·경고를 읽고 저장 확정을 받은 경우에만 반복 구간 스크롤 간격을 단축한다. 새 내용·로딩·미확인 구조·미완료 탐색은 기존 여유를 유지한다.
5. 팝업에서 재수집할 묶음 수, 현재 큐 진행, 남은 번호를 보여준다. 자료 초기화와 재수집은 별도 버튼이다.
6. 전체 회귀 시험·독립 검토·패키지 해시 검증 후 0.4.5로 전달한다. 수집 중지 확인 뒤 기존 설치 폴더를 백업·갱신하며 저장 자료는 지우지 않는다. 기존 초안 PR을 갱신한다.

## 증거와 한계

실제 사용자 기록의 미완료 사유는 아직 읽지 않았다. 재시도로 접근 불가·삭제·미지원 구조까지 완성된다고 주장하지 않는다. 가속 배수는 합성 페이지의 측정이며 실제 서비스 시간은 별도로 검증한다. 설치된 Chrome 확장의 재로드는 사용자 작업이 필요하다.

## 결과

직접 재수집 큐·팝업, 엄격한 저장 응답에 따른 0.5초 대기, 미확보 과거 멤버를 완료 근거에서 제외하는 수정과 회귀 시험을 완료했다. 독립 검토에서 찾은 지연 탭 이벤트·예상 밖 프로필 진입·다음 이동 요청 대기 중 사용자 이탈도 보완했다. 확보 개수는 미확보 번호를 제외해 표시한다. 전체 179/179, 확장 153/153 시험과 구문·공백 검사를 통과했고 0.4.5 패키지 11개 파일 해시를 대조했다. 현재 수집 중지 확인 전이므로 설치 폴더는 0.4.4를 보존한다. 상세 근거와 남은 실사용 확인은 `docs/chrome-extension-0.4.5-validation.md`에 기록했다.
