# 사진만 있는 후속 편의 상세 진입 방지

- Date: 2026-09-21
- Status: Implementation complete; installed Chrome validation pending

## Goal

프로필의 같은 묶음에 `1/2`와 사진만 있는 `2/2`가 모두 보이면 두 편을 저장하고 상세를 열지 않는다. 정말 번호가 빠진 상세 화면의 무진전 복귀 시간은 30초에서 10초로 줄인다.

## Non-goals

이미지 다운로드·OCR, 서로 다른 묶음의 추정 결합, 전체 계정 완전 수집은 포함하지 않는다.
