# 목록에서 확보한 짧은 연속글의 불필요한 진입과 상세 정체 수정

- Date: 2026-09-19
- Jira: None
- Status: Implementation and local validation complete; installed Chrome validation pending

## Goal

목록에서 1/2·2/2 본문을 확보한 경우 상세를 열지 않고 다음 글로 진행한다. 미확인 본문이 있어 상세에 들어가도 화면 변화나 답글 버튼 때문에 복귀 검사가 무기한 미뤄지지 않도록 한다.

## Non-goals

이미지 다운로드·OCR, 비공개 API, 전체 계정 완전 수집, 추가 권한은 포함하지 않는다.

## Context / Constraints

사용자가 0.4.0에서 사진이 포함된 2편 글에 진입한 뒤 진행이 멈춰 직접 중지했다. 실제 목록의 두 게시물은 같은 groupIds에 속했다. 본문은 31자·98자로 읽혔지만 사진 및 장소 태그를 미지원 본문으로 처리해 1편을 완료 판정에서 제외했다. 별도 재현에서 매 저장 중 DOM이 바뀌면 dirty 분기가 번호 확인과 30초 복귀 검사를 계속 건너뛰었으며, 바뀌는 답글 버튼도 대기 간격을 무시했다. 실제 사용자 정체가 이 경로였는지는 실행 로그 없이 단정하지 않는다.

## Approach (Checklist)

- [x] **Step 0: Recon** — 실제 문제 글 DOM·기존 코드·원격·백업 확인. 수정 전 설치 파일 11개 압축 해제 해시 일치.
- [x] **Step 1: Implementation** — 사진·장소 메타데이터와 본문 오류 분리, 같은 그룹의 전체 번호 확보 시 진입 생략, 상세 절대 상한·진전 시간·펼치기 간격 보장. 실제 저장 카드 검증 및 빈 순번의 안전한 보강.
- [x] **Step 2: Tests** — 오류 재현 후 수정, 서로 다른 2편 묶음 혼합 방지, 미확인 본문은 완료 금지, 지속 화면 변화·펼치기·로딩 중 복귀 및 저장 확인 순서 시험. 전체 116개·확장 부분집합 90개 통과.
- [x] **Step 3: Rollout / Rollback** — 같은 설치 폴더로 0.4.1 갱신, 소스·압축 해제·설치본 11개 해시 일치, 0.4.0 백업 검증. 기존 초안 PR #2에 결과 기록.
- [ ] **Installed validation** — 사용자가 확장과 Threads 탭을 새로고침한 뒤 사진 포함 2/2를 건너뛰고 긴 연속글 상세에서 복귀하는 전체 실행 확인.

## Validation

- **Commands to run:** `npm test`, `npm run test:extension`, `git diff --check`, JS 구문 검사, ZIP 및 설치본 SHA-256 비교.
- **Expected output:** 완전한 같은 목록 그룹은 상세 진입 없이 완료, 부분 목록은 상세 탐색, DOM 변화와 미지원 본문에도 복귀 기한 유지. 사진 속 글자를 확보했다는 표시는 하지 않는다. 이전 버전의 잘못된 완료 기록도 저장 카드로 재검증해 팝업·JSON·Markdown 상태를 일치시킨다.

## Risks & Rollback

- **Risks:** 가상화 목록에서 묶음 관계가 확인되지 않으면 상세로 진입한다. 사진·장소 패턴은 실제 확인된 구조만 허용한다. 상세 화면 상한은 매우 느린 로딩을 미완료로 남길 수 있다.
- **Rollback steps:** 수집을 중지·내보내고 0.4.0 백업을 같은 설치 폴더에 복원한 뒤 재로드한다. 0.4.1은 0.4.0과 같은 DB 스키마 2를 유지한다.

## Open Questions

사용자 Chrome에서 중단 전 실제 체류 시간과 화면 변화 기록은 없다. 코드로 재현된 경로와 실제 사진·장소 구조 문제를 수정하고 실제 설치 동작과 구분해 보고한다.
