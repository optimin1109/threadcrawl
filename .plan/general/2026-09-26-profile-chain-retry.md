# 프로필에서 보이는 연속글의 불필요한 상세 진입 수정

## 확인한 문제

- 사용자는 0.4.2에서 두 편 연속글이 상세 탐색에 갇힌다고 보고했다. 정확한 글은 기억하지 못한다.
- 현재 대상 프로필에서 같은 두 게시물로 구성된 묶음과 링크 없는 사진 버튼 캐러셀을 확인했다. 기존 reader는 이 사진 구조를 미확인 첨부로 처리한다.
- 현재 수집기는 첫 불완전 후보를 발견하면 다음 프로필 스크롤보다 먼저 상세를 연다. 지연 렌더링된 후속 편을 확인할 기회가 없다.

## 구현과 검증

1. 실제로 확인한 사진 버튼 구조를 익명 합성 자료로 재현하고 실패 시험을 실행한다.
2. 본문과 같은 게시물 안에 있는 확인된 사진 버튼 구조만 이미지 note로 보존한다.
3. 불완전 후보의 상세 진입 전에 한 번 프로필을 더 스크롤해 확인한다. 같은 명시적 묶음의 완성 여부만 사용하며 인접한 글을 추측으로 합치지 않는다.
4. 미해결 후보의 원래 링크가 사라진 경우에는 누락을 기록하고 다음 글을 계속 수집한다. 미확인 본문을 완료로 만들지 않는다.
5. 전체 및 확장 시험, 구문 검사, diff 검토를 실행한다. 0.4.3 패키지와 기존 설치 경로는 백업 후 파일별 해시로 검증한다.
6. 기존 작업 브랜치에 커밋/push하고 draft PR 상태를 확인한다. Chrome 확장 관리 화면은 브라우저 URL 정책으로 접근이 차단되어 재로딩/설치 실행 검증은 사용자의 도움이 필요하다.

## 경계

당시 멈춘 글을 확정하지 못했으므로 같은 증상을 만드는 확인된 결함 수정과 사용자 환경의 종단 실행 성공을 구분한다. 캡처 원문, 브라우저 상태, 이미지 URL 토큰은 커밋하지 않는다.
