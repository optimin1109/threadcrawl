# 실행 안내

현재 버전은 **실제 Threads 계정 전체 백업을 할 수 없습니다.** 합성 fixture를 이용한 실행 가능한 데스크톱 초안입니다. 입력한 계정의 실제 글을 가져왔다고 해석하지 마세요. 화면과 보고서의 `scope: fixture`가 이를 구분합니다.

## 설치 및 실행

1. Windows 10/11에서 Node.js 22 이상을 설치합니다. 별도 npm 패키지는 필요 없습니다. Windows PowerShell 5.1과 WinForms는 Windows 구성요소를 사용합니다.
2. 이 폴더 전체를 쓰기 가능한 위치에 둡니다. 파일 일부만 옮기지 마세요.
3. 루트의 `Start.cmd`를 더블클릭합니다. 이 실행에서만 PowerShell 실행 정책을 지정하며 시스템 정책을 변경하지 않습니다. 조직 정책으로 차단되면 관리자에게 확인하세요.
4. 계정명, 결과 폴더, 수집 모드를 선택하고 **수집 시작 / 이어받기**를 누릅니다.
5. `로컬 데모 - fixture 전체`는 몇 초 동안 순차 처리한 뒤 **완료 — 데모 fixture 범위만; 실제 계정 백업 아님**을 표시합니다. 모든 계정명에 동일한 합성 데이터가 사용됩니다.
6. `로컬 데모 - 일부 실패`는 정확한 부분 실패 경고를 남기고 **불완전**으로 끝납니다.
7. `실제 Threads - 미구현 사유 보고`는 네트워크 수집 없이 실패 이유를 기록하고 **불완전**으로 끝납니다.

결과는 `선택폴더/계정명/계정명.md`, `collection-state.json`, `collection-report.json`입니다. 완료 데모의 예상 수치는 발견 9개, 저장 6개, 미디어 제외 1개, 답글 제외 2개, 중복 노출 1개입니다. 발견은 고유 논리 후보 수, 저장은 결합 후 논리 게시물 수입니다. 묶음의 부분 개수와 다릅니다.

## 중지와 이어받기

**중지**를 누르거나 창을 닫으면 현재 확정된 상태를 저장하고 종료합니다. 같은 계정·모드·폴더로 다시 시작하면 마지막 확정 페이지 다음부터 읽습니다. 처리 중이던 미확정 페이지는 재시도할 수 있습니다. 완료한 데모를 다시 실행하면 기존 상태로 출력만 재생성합니다. 새 글 감시는 하지 않습니다.

모드를 바꾸려면 다른 결과 폴더를 선택하세요. fixture 내용이 바뀌면 소스 지문도 바뀌므로 기존 상태를 섞지 않습니다. 실패한 부분을 나중에 자동 보충하는 기능은 아직 없습니다. 새 어댑터나 fixture로 재검증하려면 새 폴더에서 실행하세요.

상태 파일은 이어받기의 원본입니다. 직접 수정하지 마세요. 손상되거나 지원하지 않는 스키마이면 기존 파일을 덮어쓰지 않고 오류를 표시합니다. 강제 종료 후 `진행 중` 상태가 남으면 다시 시작하여 파생 파일을 복구하세요. 서로 다른 세 파일을 동시에 원자적으로 교체하는 것은 아니므로 중간 결과는 최종본으로 사용하지 마세요. `outputGeneration`과 최종 상태를 확인합니다.

한 사용자 세션의 여러 프로그램/CLI 인스턴스는 임시 폴더 잠금 파일로 동시 수집을 막습니다. 비정상 종료의 오래된 PID 잠금은 다음 실행에서 회수합니다. 손상된 잠금 또는 PID 재사용으로 잠김이 남으면 실행 중인 수집 프로세스가 없는지 확인한 후 `%TEMP%/threads-text-archive-collector.lock`만 제거하세요. 다른 Windows 사용자 세션까지의 전역 잠금은 지원하지 않습니다.

## 전용 Chrome

**전용 Chrome 수동 확인**은 설치된 Chrome을 새로운 빈 프로필로 엽니다. 처음에는 비로그인 상태이고, 자동으로 읽거나 스크롤하거나 로그인하지 않습니다. 평소 프로필, 쿠키, 비밀번호를 읽거나 복사하지 않습니다. 디버깅 포트도 열지 않습니다.

실제 수집과 연결된 로그인 필요 감지·사용자 계속하기 흐름은 미구현입니다. 지금은 수동 조사 창입니다. 사용자가 그 창에서 직접 로그인하면 Chrome 자체가 `%LOCALAPPDATA%/ThreadsArchive/BrowserProfiles/<무작위값>`에 브라우저 데이터를 저장할 수 있지만 결과 폴더에는 인증 정보를 저장하지 않습니다. 각 클릭은 새로운 프로필을 만듭니다. 조사 후 해당 Chrome 창을 닫고 원하면 이 전용 BrowserProfiles 폴더를 제거할 수 있습니다. 계정 정지 위험이 없다고 보장하지 않습니다.

## 개발자 실행

프로젝트 루트에서 아래 명령을 사용합니다. `package.json`에 대응 명령이 정의되어 있습니다.

```powershell
node --test tests/*.test.mjs
node src/cli.mjs --account demo_account --output output --source demo
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File src/gui.ps1 -SmokeTest
```

GUI smoke는 실제 WinForms 이벤트와 자식 Node 프로세스로 시작·중지·이어받기를 실행하고 `output/gui-smoke-*/gui-demo.png`를 만듭니다. 사용자의 Chrome은 실행하지 않습니다. CLI의 Ctrl+C도 상태 저장 후 중단합니다. `--source partial` 또는 `--source live`는 별도의 출력 폴더와 함께 사용하세요.

`scripts/create-fixtures.mjs`는 유지보수용 합성 fixture/스키마 재생성 도구입니다. 일반 실행에 필요하지 않습니다. 외부 패키지 설치, 웹 서버, 빌드, .NET SDK 없이 실행합니다. 독립 실행 EXE/설치 프로그램은 아직 제공하지 않습니다.

## 제거

프로그램 폴더를 제거하면 됩니다. 별도 선택한 결과 폴더는 보존됩니다. GUI 실행 통신 파일은 `%TEMP%/threads-run-*`에 남으며 인증 정보는 포함하지 않습니다. 필요하면 프로그램을 종료한 후 제거하세요.
