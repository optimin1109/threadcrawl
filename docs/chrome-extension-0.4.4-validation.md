# Chrome 확장 0.4.4 검증

## 문제와 실제 화면 근거

사용자가 제보한 상세 화면 두 곳을 수집 탭과 별도의 Chrome 탭에서 읽었다. 한 첫 편은 `이용할 수 없는 게시물` 안내 때문에, 다른 두 편은 외부 뉴스 미리보기 때문에 미확보로 계산됐다. 각 본문은 정상 단락 구조이고 자체 시각 링크는 하나이며 중첩 게시물은 없었다. 기존 reader가 지원하지 않는 본문 뒤 구조를 오류로 남기면 연속글의 완료 검증에서 그 번호를 제외하는 것이 원인이다.

- 이용 불가 안내: 관측한 외부 DIV 클래스와 DIV → SPAN 구조, 정확한 안내문, 다른 콘텐츠·조작 요소 없음이 새 조건과 일치했다. 첫 편 순번은 `1/3`이었다.
- 링크 미리보기: 이미지가 있는 첫 편과 없는 두 번째 편 모두 관측한 구조가 새 조건과 일치했다. 순번은 `1/2`, `2/2`, 서비스 배지를 제외한 판독 텍스트 길이는 JavaScript 문자열 기준 294자·310자였다.
- 직접 관측한 제목·도메인과 Threads 리디렉션의 목적 주소만 별도 정보로 남긴다. 외부 기사에 접근하거나 전문·미리보기 이미지를 저장하지 않는다. 실제 게시물 원문과 추적/CDN 토큰을 시험 자료나 저장소에 넣지 않았다.

## 변경 범위

본문과 순번 검증은 유지하고, 확인된 안내 및 링크 미리보기만 비차단 note로 분리했다. 미확인 구조·중첩 인용·서로 다른 확정 순번은 계속 미완료로 남긴다. Markdown은 별도 정보를 본문과 구분하고 저장하지 않은 외부 원문을 명시한다. 안전한 HTTP(S) 목적 주소만 링크로 출력하며 추적 리디렉션은 저장하지 않는다.

팝업에 마지막 수집 계정 이름이 표시되는 초기화 버튼을 추가했다. 중지한 뒤 삭제 범위와 복구 불가 안내에 확인해야 해당 계정의 글·연속글·오류·진행 기록을 한 트랜잭션으로 삭제한다. 다른 계정과 내보낸 파일은 보존하고 이전 실행의 늦은 메시지를 거절한다. 실제 사용자 기록은 삭제하지 않았다. 권한 및 DB 버전은 변경하지 않았다.

## 검증

- reader의 새 정상 구조 시험 두 개, 프로필에서 상세를 생략하는 통합 시험 두 개가 수정 전 실패했다. 알려진 구조 처리 뒤 통과했다. 예상하지 못한 URL·조작 요소·텍스트는 계속 오류가 된다.
- 계정 초기화 시험 아홉 개가 구현 전 실패하고 구현 후 통과했다. 다른 계정 보존, 중간 실패 전체 복구, 실행 중 삭제 거부, 대상 변경, 취소, 오래된 메시지 차단을 포함한다.
- 기존 첨부 오류 자료를 다시 읽어 본문·노트·순번을 보강하면 JSON과 연속글 완료 수가 일치한다.
- 수정 전 추가한 Markdown 시험 세 개가 실패하고 수정 후 통과했다. 출력 주입·위험한 URL을 차단하며 본문 공백·줄바꿈과 입력 JSON을 바꾸지 않는다.
- 전체·확장 시험 결과와 최종 패키지 해시는 아래 배포 결과에 기록한다.
- 독립 검토에서 발견한 외부 IPv6 주소의 대괄호 인코딩 문제도 회귀 시험 후 보완했다.

## 남은 확인

실제 DOM 조건 대조와 합성 브라우저 시험은 설치된 확장의 자동 수집·복귀·파일 저장 성공을 뜻하지 않는다. Chrome 확장 관리 페이지는 도구의 URL 정책상 접근할 수 없어 재로드는 사용자가 해야 한다. 사용자의 수집 중지 확인 후 기존 설치 폴더를 갱신했으며, 초기화는 실제 사용자 자료로 실행하지 않았다.

완전한 과거 범위, 알 수 없는 첨부, 일반 중첩 인용, 숨겨진 후속 글은 미검증이다. 기존 10초 무진전·120초 상세 상한과 45분 수집 상한은 유지한다. GitHub의 원격 Checks와 로컬 시험 결과는 구분한다.
