# Threads 텍스트 보관 0.3.0

현재 Chrome에서 보고 있는 공개 Threads 프로필의 소개글과 긴 텍스트 첨부를 저장합니다. 설치 후 확장 버튼을 눌러 직접 시작하며, 추가 로그인·API 키·외부 수집 서비스는 필요하지 않습니다.

## 설치와 실행

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `manifest.json`이 들어 있는 폴더를 선택합니다. ZIP 파일 자체를 선택하지 않습니다.
4. `https://www.threads.com/@hongso0921`을 엽니다. 기존에 열려 있던 탭은 새로고침합니다.
5. Chrome의 확장 메뉴에서 **Threads 텍스트 보관 — 실험판**을 열고 **이 계정 수집 시작 / 계속 누적**을 누릅니다.
6. 필요한 만큼 진행한 뒤 **중지**, **읽을 문서 저장 (Markdown)**을 누릅니다. 재가공용 자료는 **원본 자료 저장 (JSON v2)**로 함께 저장합니다.

팝업은 닫아도 됩니다. 수집하는 Threads 탭은 열어 두세요. 자동 탐색은 최대 45분 또는 1,800회이며, 30초간 새 내용이 없거나 로그인·보안 안내가 나타나면 멈춥니다. 사람이 확인해야 하는 보안 절차를 자동 처리하지 않습니다.

## 저장과 계속 누적

- 확인한 글은 계정별 IndexedDB에 저장하며, 화면을 넘기기 전에 저장 확정을 기다립니다.
- 탭을 닫거나 새로고침해도 이미 확정한 글은 남습니다. 다시 시작하면 현재 화면부터 기존 게시물 ID와 대조해 누적합니다. 이전 스크롤 위치를 자동 복원하지는 않습니다.
- 뒤늦게 나타난 긴 첨부는 기존 글에 보강합니다. 내용이 충돌하면 최초 내용을 보존하고 경고를 남깁니다.
- JSON/Markdown은 마지막으로 시작한 계정의 자료입니다. 다른 계정 자료를 다시 내보내려면 해당 계정에서 시작 후 중지하세요.
- 확장 삭제나 브라우저 프로필 삭제 전에 파일로 내보내세요. 이전 실험판의 `chrome.storage` 데이터는 건드리지 않으며 자동 이전하지 않습니다.

## 확인된 범위와 한계

2026-09-19 실제 `@hongso0921` 프로필 DOM에서 소개글 66자와 긴 첨부 7,835자(줄바꿈 62개)를 분리했습니다. 첨부는 펼친 원문과 정확히 일치했습니다. 후속글의 다른 본문 구조도 확인해 지원합니다. 이는 실제 DOM 읽기 검증이며, Chrome에 설치한 확장 전체 실행 검증과 구분합니다.

전체 과거 글, 숨겨진 추가 답글, 인용·중첩 글, 미디어 전용 글은 완전 수집을 보장하지 않습니다. 모르는 구조는 해당 게시물 링크와 경고를 남깁니다. `1/3`, `2/3` 등은 각각 보존하며 자동으로 하나의 글로 결합하지 않습니다. 고정된 오래된 글의 날짜만으로 과거 목록 전체를 확보했다고 판단하면 안 됩니다.

Markdown은 원문 줄바꿈과 공백을 보존하는 텍스트 블록을 사용합니다. JSON은 **v2**이며 기존 데스크톱의 v1 가져오기와 호환되지 않습니다.

## 권한과 검증

권한은 `activeTab`, `scripting`, `storage`입니다. 사용자가 실행한 탭의 DOM만 읽으며 쿠키·비공개 API·외부 서버 전송을 사용하지 않습니다.

개발 검증: 저장소 루트에서 `npm ci`, `npm test`, `npm run test:extension`. 설치 자체에는 Node나 npm이 필요 없습니다. 회귀 시험은 긴 첨부, 후속글, 숨은 팝업, 저장 실패·재개방, 오래된 실행 메시지, 저장 후 스크롤, Markdown 보존을 검증합니다.
